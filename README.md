# 24 小时太阳钟 · 天人合一

指针一圈走过一天，观指针而知日之所在，作息顺应天时。

一个纯前端的 PWA：原生 HTML / CSS / JavaScript + Canvas 2D，无框架、无后端、无数据库，可离线安装到手机或平板主屏常亮展示。

## 项目立意

- **构思、表盘规则与界面设计由本人提出并逐轮迭代**；代码在 AI 辅助下完成，AI 仅作为编码工具。
- 核心想法：把传统 12 小时表盘改成 **24 小时一圈**，让指针对应太阳在天上的方位——正午 12 点指针到顶，午夜 0 点指针落底，日出而作、日落而息，人与天同频。
- 本项目为个人学习交流用途，非商用；欢迎自由使用、修改与转发。

## 表盘规则

- **一圈 24 小时**：0 在脚下、12 在当头；6 在左、18 在右。
- **太阳即指针**：正午太阳最高，指针指向表盘顶端；午夜指向底部；指针指到哪，太阳便在天上对应何方。
- **内圈分钟刻度**：每分钟一条短线，每 5 分钟标一个数字（00 / 05 / 10 … 55）。
- 角度换算：`角度 = 270° + (小时 - 12) × 15°`。

## 功能

- **时区选择**：跟随本机时区，或手动选 UTC-12 ~ UTC+12:45 各时区偏移。
- **经度真太阳时**：输入当地经度（东经为正、西经为负），按 `UTC + 经度 / 15` 计算真太阳时。
- **长汀一键按钮**：点「长汀」直接填入福建长汀东经 116.36°，切到真太阳时。
- **四套主题**：暗夜星空、晨曦暖阳、清新晨光、墨夜鎏金；选择记住在本地。
- **PWA 离线**：Service Worker 缓存，可添加到主屏，断网仍可显示。

## 技术栈

- 原生 HTML5 + CSS 变量主题 + 原生 JavaScript（ES5 风格，兼容较老的 WebView）。
- 表盘与刻度用 Canvas 2D 绘制；背景主题图在 `assets/`，图标在 `icons/`。
- Service Worker 优先网络、失败回退缓存；`manifest.webmanifest` 定义独立窗口展示。

## 版本号规范

格式：`YYYYMMDD.N`

- **前半 `YYYYMMDD`**：发布当天日期，年 4 位 + 月 2 位 + 日 2 位，如 `20261115`。
- **后半 `.N`**：当天第几次发布，从 `1` 起；同一天反复改就递增；跨到新一天，日期换成当天、N 重置为 `1`。
- 例：`20261115.1` → 当天又改 `20261115.2` → 明天再改 `20261116.1`。

更新规则：

1. 改了页面 / 样式 / 逻辑 / 素材就升版本；纯注释、不影响运行的小文案可不动。
2. 两处必须写同一版本：`index.html` 底部「版本 x」＋ `sw.js` 的 `APP_VERSION`。
3. 缓存名 `sun-clock-<版本>` 由 `APP_VERSION` 派生，无需单独改。
4. 不升版本直接部署，已安装的老设备可能吃到缓存旧版。

## 本地运行

静态站点，任选一种方式起本地服务即可：

```bash
# 在本目录下
python -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

直接双击 `index.html` 打开也能看，但部分浏览器对本地文件下的 Service Worker 有限制，建议用本地服务器预览。
